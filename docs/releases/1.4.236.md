ShellShifter 1.4.236

For Maya 2025 and 2027 on Windows.

- Set Selected now finds originals on meshes in nested namespaces. Counts,
  original preference, scene persistence and Undo/Redo work with those meshes.
- Material selection uses the same rounded gray highlight in both Maya versions;
  Maya 2027's square blue selection background is covered by the custom delegate.
- Shift + wheel handles native UV-editor QWindow events and uses one shared
  handler that stays active after the palette closes. Angle, HUD and Undo remain.
- Unwrap Mesh pauses plugin preview/UI reads while UVs are projected, cut and
  unfolded. Buttons finish their Qt callback before Maya edits the mesh.
- Added preflight checks for non-manifold vertices and native-solver guards for
  degenerate geometry or unresolved folded UVs, with safe legacy unfolding first.

Verified with 247 behavioral tests in each Maya version, plus native gesture,
material/original UI and sample Unwrap checks. The reported individual Maya 2027
crash did not reproduce on the tested cube or Unfold_Good/Unfold_Bad FBX files;
these safeguards address unsafe solver input and reentrant preview updates.

Install the ZIP for your Maya version, extract all files and drag
install_shellshifter.py into Maya's 3D viewport. Save your scene and restart Maya
after updating.
