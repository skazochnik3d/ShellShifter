ShellShifter 1.4.237 — установка для Maya 2025 / 2027
================================================

Требования
----------
Проверенная среда: Windows, Autodesk Maya 2025 / 2027.
Python, Qt и NumPy используются из комплекта Maya: отдельно устанавливать их
не нужно. Для GPU-паковки требуется видеокарта с OpenCL 1.2 и поддержкой
двойной точности (FP64), а также драйвер с OpenCL. CUDA Toolkit, PyOpenCL
и UVPackmaster не требуются. Unwrap Mesh использует штатный Unfold3D Maya.

Установка
---------
1. Полностью распакуйте ZIP в постоянную папку с правом записи, например
   в Documents\MayaTools. Внутри появится папка ShellShifter_1.4.237.
2. Откройте Maya 2025 / 2027 и выберите вкладку Shelf, куда хотите добавить кнопку.
3. Из Проводника перетащите install_shellshifter.py из распакованной папки
   в 3D-вьюпорт Maya. Не перетаскивайте ZIP или shellshifter.py.
4. На выбранной полке появится кнопка ShellShifter с подписью SS,
   и панель плагина откроется автоматически.
5. В меню Shelf выберите Save All Shelves, чтобы сохранить кнопку.
6. После перезапуска Maya нажмите SS для запуска плагина.

Не перемещайте и не удаляйте распакованную папку после установки: кнопка
запоминает путь к ней. Все файлы uv_straight*.py и подпапка assets должны
оставаться рядом с shellshifter.py и install_shellshifter.py. Установщик
добавляет кнопку на полку; файлы остаются в выбранной вами папке.
Он не требует прав администратора и не изменяет userSetup.py.

Если перетаскивание не сработало
------------------------------
Откройте Windows > General Editors > Script Editor, выберите вкладку Python
и выполните следующий код, указав путь к своей распакованной папке:

    import sys
    folder = r'C:\path\to\ShellShifter_1.4.237'
    if folder not in sys.path:
        sys.path.insert(0, folder)
    import install_shellshifter
    install_shellshifter.onMayaDroppedPythonFile()

Это тот же установщик: он создаёт кнопку Shelf и открывает панель.

Первый запуск и основные действия
---------------------------------
Откройте UV Editor и выберите меш, UV или UV-шеллы.
В боковой колонке ShellShifter выберите нужный раздел:
- Unwrap: Unwrap Mesh делает разрезы по выбранным рёбрам и хардам,
  строит начальную развёртку по геометрии и улучшает её анфолдом без пинов.
  Дополнительный проход по длинам рёбер и диагоналей уменьшает изгибы
  и неравномерное растяжение. Затем выполняет Orient Shells и быструю
  автоматическую паковку без отдельного окна. H/V-пины автоматически не
  назначаются; старые пины снимаются. Вся операция отменяется одним Undo.
  Unfold и Relax используют заданные вами пины.
- Packing: Pack UVs для выбранных шеллов; Pack to Other для размещения
  выбранных шеллов рядом с оставшимися, без перемещения последних.
- Packing: To Square растягивает выбранные шеллы из нижней половины
  на весь квадрат: V ×2 относительно V=0. To Rectangle сжимает обратно:
  V ×0,5. U не меняется; при выборе части шелла меняется весь шелл.
  Каждое преобразование отменяется одним Undo.
- Packing: UV Area задаёт область паковки: Square — весь тайл,
  Bottom Half — нижняя половина тайла: U 0–1, V 0–0,5.
  Форма шеллов сохраняется. Отступы считаются от границ выбранной области
  в пикселях квадратного Texture Size. Pack UVs и Pack to Other используют
  эту настройку; свободное место считается относительно выбранной области.
- Orient & Straighten: Orient Shells поворачивает весь выбранный шелл к
  ближайшей оси U/V с поворотом не более 45°. Две UV-точки задают линию;
  несколько точек — направления выбранных сторон. Форма и масштаб сохраняются.
- Orient & Straighten: Straighten Quads выпрямляет выбранные
  квадовые шеллы и ставит H/V-метки по границе. Завершающий Unfold
  не запускается; вся операция отменяется одним Undo.
- Materials: компактные кнопки с полными именами материалов в две колонки.
  Список заполняется слева направо, без вложенных групп. Клик выбирает UV,
  Ctrl добавляет материалы, Shift выбирает диапазон. Полное длинное имя
  видно в подсказке. Используется текущий UV set каждого объекта.
- UV Checks: настройки пикселей и разрешения находятся в начале группы Shells & Edges. Кнопки
  собраны по задачам: Shells & Edges, Overlaps и UV Sets.
- UV Checks: Select Overlaps выбирает все пересекающиеся шеллы. Check Overlaps
  выделяет проблемные шеллы; совпадение по площади UV от 99% допустимо.
  Совпадение считается как площадь пересечения / площадь объединения.
- UV Checks: Fix Butterfly Overlaps восстанавливает сшитые границы складок
  на выбранных объектах или шеллах. Координаты UV сохраняются, доступен Undo.
- Move Overlaps: Stack Similar Shells совмещает выбранные копии с одинаковой
  топологией и геометрией поверхности по наименее искажённому образцу.
  Корректируются все UV-точки текущего UV-сета. Один Undo возвращает все
  шеллы и H/V-метки; один Redo снова применяет стак.
  Функцию можно назначить в Pie Menu и Keymaps. Несовместимые шеллы пропускаются.
- Distortion: после восстановления пропорций шелла ложная заливка исчезает.
  Расчёт использует текущие UV и обновляется при Undo/Redo.
- Display: Wireframe скрывает и возвращает сетку мешей в 3D-вьюпортах.
  Show H/V Pins и Show Distortion остаются независимыми настройками.
  UV, выделение, цвета и история Undo сохраняются.
- Texel Density: Analyse & Show включает автоматическое обновление цветов
  после изменения UV и Undo/Redo. Зелёный соответствует среднему текселю
  в начале анализа; Clear выключает отображение.
- Pie Menu: названия функций совпадают с кнопками панели. Старые
  стандартные подписи обновляются при загрузке без перестановки функций.
  Edit Pins: короткий клик добавляет или снимает H/V-сегмент;
  перетаскивание передаётся инструменту Maya и сохраняет H/V-метки.
- Keymaps: настройка сочетаний клавиш и редактор Pie Menu.

Сочетания по умолчанию работают после открытия ShellShifter:
- Alt + Shift + правая кнопка мыши: Pie Menu над UV Editor/3D-вьюпортом.
- Shift + Space: всплывающее меню.
- Shift + колесо мыши: угол Auto H/V. При изменении угла над курсором появляется
  значение в градусах и плавно исчезает после остановки прокрутки.

Для отдельной паковки по умолчанию: Texture Size 2048, Shell Spacing 10 px,
Border Margin 5 px, Search Limit Unlimited. Размер текстуры задайте под свой
проект. При Unlimited поиск продолжается до Stop and Keep Best: эта кнопка
останавливает поиск и применяет лучший полностью рассчитанный результат.
Значения и назначения клавиш сохраняются в настройках Maya этого пользователя.
Enable Undo в настройках Maya должен быть включён для операций с UV.

Обновление
----------
Откройте раздел Updates с зелёной круговой стрелкой. Check for Updates проверяет
публичные релизы https://github.com/skazochnik3d/ShellShifter.
После открытия плагина проверка идёт автоматически в фоне, затем повторяется
каждые 4 часа, пока Maya работает. Если доступна новая версия для вашей Maya,
появится окно с кнопками Download & Install и Later. Проверяется также beta.
Установка начинается только по кнопке. Остановите текущую UV-операцию перед
установкой. Проверяются SHA-256 архива и всех файлов; при ошибке замены файлов
восстанавливается предыдущий комплект. Резервная копия остаётся рядом с плагином
в папке ShellShifter_backup_*. Сцена, Shelf, хоткеи и userSetup.py не меняются.
После сообщения Update installed сохраните сцену и перезапустите Maya.
Повторный запуск SS откроет новую версию. Обновлять Shelf не нужно.
При недоступной сети ошибка показывается в подсказке кнопки Check for Updates без всплывающих окон.

Ручное обновление: закройте Maya и замените весь комплект файлов новой версией
в прежней папке. Если путь меняется, повторите установку и сохраните Shelf.

Удаление
--------
Удалите кнопку SS с полки и сохраните Shelf. Закройте Maya, затем
удалите распакованную папку ShellShifter.

Если возникает ошибка
---------------------
- No module named shellshifter: проверьте, что папка не перемещена и архив
  распакован полностью. Повторите установку из действующей папки.
- OpenCL / GPU: проверьте поддержку OpenCL/FP64 и драйвер видеокарты.
  GPU-паковка не переключается автоматически на CPU.
- Unfold3D: проверьте, что штатный Unfold3D доступен в Maya Plug-in Manager.
- После ошибки сохраните текст из Script Editor и укажите версию Maya,
  версию ShellShifter и модель видеокарты при обращении к автору.

Комплект содержит рабочие модули и ресурс чекера. Тестовые сцены, FBX,
резервные копии, профили пользователя Maya и файлы разработки не включены.

Straighten Quads также распрямляет подходящие открытые ленты с треугольниками
и n-гонами по длинным сторонам: назначает H/V-метки и выполняет Unfold с ними.
Для полностью квадовых шеллов завершающий Unfold не выполняется.
