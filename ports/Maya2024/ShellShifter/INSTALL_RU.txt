ShellShifter 1.4.252 — установка для Maya 2024
================================================

Требования
----------
Требования: Windows x64 и Autodesk Maya 2024.
Плагин использует Python и Qt из Maya. Если NumPy отсутствует, ShellShifter
распакует копию из архива в локальную папку приложения при первом запуске.
Для GPU-паковки требуется видеокарта с OpenCL 1.2 и поддержкой
двойной точности (FP64), а также драйвер с OpenCL. CUDA Toolkit, PyOpenCL
и UVPackmaster не требуются. Unwrap Mesh использует штатный Unfold3D Maya.

Установка
---------
1. Полностью распакуйте ZIP во временную папку.
2. В Maya 2024 выберите вкладку Shelf для кнопки.
3. Перетащите install_shellshifter.py в 3D-вьюпорт.
4. Maya скопирует плагин в папку scripts своей версии и сохранит кнопку Shelf.
   Если ShellShifter уже был загружен, сохраните сцену и перезапустите Maya.
5. Теперь можно удалить ZIP и распакованную папку.

Если перетаскивание не сработало
------------------------------
Откройте Windows > General Editors > Script Editor, выберите вкладку Python
и выполните следующий код, указав путь к своей распакованной папке:

    import runpy
    folder = r'C:\path\to\ShellShifter_1.4.252'
    runpy.run_path(folder + '/install_shellshifter.py')['onMayaDroppedPythonFile']()

Это тот же установщик: он создаёт кнопку Shelf и открывает панель.

Для удаления установленной копии нажмите Uninstall ShellShifter в Updates.
